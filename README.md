# Виртуальный музей Оленёкской СОШ

Сайт виртуального школьного музея Оленёкской средней общеобразовательной школы
(с. Оленёк, Оленёкский эвенкийский национальный район, Республика Саха (Якутия)).

## Разделы сайта

- **О музее** — краткий рассказ о музее.
- **Залы** — пять тематических залов: история школы, культура и быт эвенков,
  память поколений, природа края, учителя и выпускники.
- **Виртуальная экскурсия** — пошаговый проход по залам.
- **Коллекция** — все экспонаты с поиском и фильтром по залам; по нажатию
  открывается карточка экспоната.
- **Школьная жизнь** — фотогалерея (массив `PHOTOS` в `js/data.js`).
- **Летопись** — основные вехи истории.
- **Контакты** — как связаться с музеем и передать экспонат.

## Как открыть

Откройте файл `index.html` в браузере. Сервер и сборка не нужны.

## Как добавить или изменить экспонаты

Всё содержимое музея находится в файле `js/data.js`:

- `HALLS` — залы музея;
- `EXHIBITS` — экспонаты;
- `TIMELINE` — летопись.

Чтобы добавить фотографию экспоната, положите файл в папку `images/`
и укажите путь в поле `image`, например:

```js
{ hall: "evenki", title: "Эвенкийская парка", period: "1950-е годы",
  text: "Описание…", donor: "Иванова А. П.", image: "images/parka.jpg" },
```

Описания экспонатов в `data.js` — образцы: замените их сведениями о
настоящих предметах музея. Контакты (ФИО руководителя, почта) заполняются в
`index.html`, раздел `contacts`.

## Публикация в интернете

Сайт можно бесплатно разместить через GitHub Pages:
**Settings → Pages → Deploy from a branch**, выбрать ветку и папку `/ (root)`.
